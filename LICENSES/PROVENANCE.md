# Provenance

Every file in this repository that did not originate here, where it came from,
and under what licence. All of it is MIT.

## The library

| file | origin | licence |
|---|---|---|
| `lib/aklplayer.asm` | Written for the Edge Grinder BBC port (`BEEB/Repos/edge-beeb`, 2026-09-04) as a 6502 rewrite of Arkos's `PlayerLightweight.asm`. Not a transcription — the Z80 is built on self-modifying code and `ld sp,` as a data pointer. | MIT (this repo) |
| `lib/akyplayer.asm` | Converted from `reference/PlayerAky_atari_mads.asm` — Krzysztof Dudek (xxl)'s Atari 8-bit port of Targhan's Z80 AKY player. MADS→BeebASM, and the AY register writes redirected into `ay_regs`. | MIT (see below) |
| `lib/ay2sn.asm` | Written for the Edge Grinder BBC port. `sn_write` within it is from `lib/vgiplayer.asm` in `BEEB/Repos/vgm-player-bbc` (Simon M, MIT). | MIT |
| `lib/akmplayer.asm` | Written here as a 6502 rewrite of `reference/PlayerAkm_z80.asm`. Not a transcription: the Z80 uses `ld sp,` as a data pointer and self-modifies its own instruction operands for every song-header value. | MIT (this repo) |
| `lib/akm_periods.asm` | Generated by `tools/make_tables.py` from `PLY_AKM_PeriodTable` (the 1 MHz CPC branch of `reference/PlayerAkm_z80.asm`) and that player's own octave-shift arithmetic. **Not the same table as `akl_periods.asm`** - see `docs/format-akm.md`. | MIT (Arkos, derived) |
| `lib/akl_periods.asm` | Extracted from `reference/PlayerLightweight.asm` (`PLY_LW_PeriodTable`, the 1 MHz CPC branch) by `tools/make_tables.py`. | MIT (Arkos) |
| `lib/ay2sn_tables.asm` | Generated by `tools/make_tables.py`. | MIT (this repo) |

The AKM player ships its **own** copy of the licence alongside its source, and
`arkos-tracker3-playerakm.txt` is that copy. It is the same MIT text, the same
holder and the same years as `arkos-tracker3.txt`, differing only in line
wrapping and in spelling Nevo with its accent - it is kept separately because
that is how Arkos ships it, and because AT3 deleting the Lightweight sources
is proof that what an install contains today it may not contain tomorrow.

**The two Lightweight files are kept here deliberately.** Arkos Tracker 3 has
removed the Lightweight player, its documentation and its exporter. AT2 is the
only place they still exist, and AT2 is no longer distributed.

Arkos Tracker 2 shipped no `LICENSE` file; its terms were stated only on the
website, and `arkos-faq-at2.md` is that statement archived. Arkos Tracker 3
ships `LICENSE.txt`, which is what `arkos-tracker3.txt` is.

Crediting Arkos is explicitly non-mandatory. This repository does it anyway,
in the README, because it would not exist otherwise.
